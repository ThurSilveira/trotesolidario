# Trote Solidário Uni-FACEF 2025

Este projeto foi desenvolvido durante o primeiro semestre de 2025 como uma atividade acadêmica do curso de Engenharia de Software do Uni-FACEF.

Neste último commit, o projeto foi atualizado e reorganizado. O repositório `cardtrote` foi incorporado ao projeto principal, os arquivos foram agrupados por finalidade e os caminhos de navegação foram ajustados para manter toda a aplicação em um único repositório.

## Estrutura

- `index.html`: página inicial;
- `pages/`: páginas de conteúdo, calculadora e card de perfil;
- `assets/css/`: folhas de estilo;
- `assets/js/`: scripts da aplicação;
- `assets/images/`: imagens utilizadas nas páginas.

## Execução

Abra o arquivo `index.html` no navegador ou publique a raiz do repositório com o GitHub Pages.
